# Knihovna ikon katalogu

- `crypto/*.png` + `crypto.json` — ikony kryptoměn (128 × 128) ze sady
  [cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons) 0.18.1, licence CC0 1.0 (`crypto/LICENSE.md`).
  Vybráno 100 nejběžnějších; dalších 12 (ALEPH, AUCTION, CELO, CLV, FET, FORTH, GAL, IOTX, LUNA, NEAR, NU, RNDR) je
  z vlastní sbírky autora — mimo licenci CC0, ochranné známky svých vlastníků. Další jde nahrát ručně.
- `etf/*.png` + `etf.json` — loga hlavních správců ETF (128 × 128, převedená z ikon instrumentů XTB). Ochranné známky
  svých vlastníků, slouží jen k označení fondu.
- `institutions-cz.json` — české banky, brokeři, burzy, peněženky a penzijní společnosti s webem. Logo se na pokyn
  uživatele stáhne z webu instituce; u webů, odkud to nejde (ochrana proti robotům, jen ICO), je přibalené logo
  v `institutions/*.png` (pole `icon`). Loga jsou ochranné známky svých vlastníků, slouží jen k označení instituce.
