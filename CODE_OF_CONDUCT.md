# Code of Conduct

Projekt se řídí [Contributor Covenant, verze 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(česky: [Kodex chování přispěvatelů](https://www.contributor-covenant.org/cs/version/2/1/code_of_conduct/)).

Stručně: buďme k sobě slušní a vstřícní, kritizujme kód, ne lidi, a respektujme odlišné názory a zkušenosti.
Obtěžování, urážky ani zveřejňování cizích osobních údajů tu nemají místo.

Nevhodné chování hlas správci projektu na `jindrichmach@gmail.com`. Každé hlášení se posoudí důvěrně
a správce může podle závažnosti napomenout, dočasně nebo trvale vyloučit z projektu.

---

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Report unacceptable behaviour to the maintainer at `jindrichmach@gmail.com`; all reports are handled confidentially.
